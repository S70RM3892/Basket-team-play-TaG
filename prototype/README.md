# TaG プロトタイプ v0.3 — 1on1 アビリティじゃんけん（Godot 4.7）

## v0.3の変更：基本操作の組み合わせでシュートの種類が変わる
専用のボタンは増やさない。**スティックの向き（リングに対して↑前・↓後ろ）× シュート × ジャンプ × 突破** の組み合わせで決まる。

| シュート | 入力 | 条件 | 体の動き | 性質 |
|---|---|---|---|---|
| ジャンプショット | RT | 止まっている、または横に動いている | その場で止まって跳ぶ | 標準 |
| レイアップ | ↑+RT | リングまで3.2m以内 | 2歩踏み込んで跳ぶ（ギャザー） | 成功率が高い。ブロックされやすい |
| フローター | ↑+RT | リングまで3.2〜5.5m | 前に流れながら高い弧 | ブロックに強い |
| ステップバック | ↓+RT | どこでも | 後ろへ跳び退いて間合いを作ってから跳ぶ（アークの外に出れば2点） | 寄せを外す |
| フェイダウェイ | A→空中で↓+RT | 空中 | 後ろに流れながら打つ | 寄せとブロックに強い。成功率は少し下がる |
| ダンク | LB突破→RT | 突破中または直後、リングまで1.9m以内 | 突っ込んで叩き込む | ほぼ入る。ゴール下で跳んでいる相手には叩かれる |
| ユーロステップ | LB突破→RT | 突破中または直後、1.9〜3.6m | 横に1歩ずらしてから踏み込む | 寄せとブロックに強い |

- どのシュートも自動ジャンプの頂点が「パーフェクト」付近に来るように、溜めの速さを種類ごとに変えてある。**跳んで、頂点で離す** と入る。
- 溜めている間は、画面に「シュートの種類＋成功率」が出る。
- 突破からダンクやユーロステップにつないだ直後の0.2秒は、まだ「突破」扱い。タックルを読まれていれば止められる（じゃんけんは崩さない）。
- シュート妨害（RB長押し）は、どの種類のシュートにも勝つ（じゃんけんのまま）。種類によって変わるのは、**ふつうの寄せ（距離）とブロック** への強さ。
- BOTも状況に応じて種類を使い分ける（寄られたらステップバックかフェイダウェイ、近ければレイアップ、突破中にリングが近ければダンクかユーロステップ）。


## v0.2の変更（v0.1を遊んだ感想「読み勝っても手応えがない／BOTが強い／シュートが全く入らない」への対応）
| 問題 | 原因 | 対応 |
|---|---|---|
| シュートが全く入らない | 照準がリングから14°以上ずれると成功率が0.3倍になっていた。目の前のBOTを見たまま打つと、ほぼ必ずこれに引っかかる。良いタイミングの幅も約0.08秒しかなかった。さらにBOTの反応的な妨害で×0.35 → 実際の成功率は1割前後 | **ロックオン**：溜めている間、視点がリングへ自動で吸い付く。タイミングの「良い」幅を約0.3秒に広げ、真ん中に「パーフェクト」（×1.12）を追加。基本の成功率も上げた。**溜めている間に成功率を％で表示する**（妨害されていると赤くなる） |
| BOTが強い | BOTは照準のずれがほぼなく、こちらのシュートの溜めを見てから妨害を出せた | BOTも同じタイミングの判定で外すようにした。見てからの反応の確率を下げた。強さを4段階（練習／ふつう／強い／鬼）にし、初期値は「ふつう」 |
| 読み勝っても手応えがない | 勝っても相手はすぐ動けて、こちらの得も小さかった。演出も小さな文字だけ。BOTは完全にランダムに手を選ぶので、そもそも「読む」材料がなかった | **ヒットストップ→スロー、画面のフラッシュ、効果音、大きな「読み勝ち！」**。負けた側は1秒以上動けず（タックル＞突破ならボールはそのまま奪える、間合い＞かわしなら自動でスティール）、勝った側は2秒間「ゾーン」（速くなり、相手の寄せを無視して次のシュートが入りやすい）。**BOTに試合ごとの「クセ」**（好きな手が2.5倍出やすい）を持たせ、試合終了時に答え合わせを表示する。弱いBOTは技の前に「構え」が見える |
| （おまけ） | 一人称では、相手と自分の動きが見えにくい | ポーズ中にLBで **三人称カメラ** に切り替えられる |


[docs/RULES_V1.md](../docs/RULES_V1.md) §7「次の検証（P1）」を確かめるための、最小のプロトタイプ。
一人称視点の1on1をBOTと戦う。コントローラーに対応したAndroid用APKとして書き出す。

## 入っているもの
- **普通のバスケ（3x3方式）**：アーク内1点・外2点、11点先取、ショットクロック12秒、守備側がボールを取ったらアーク外へクリアしてから攻める、アウト・オブ・バウンズ
- **一人称**：照準でリングを狙い、溜めて離すタイミング（緑の範囲）でシュートの成功率が決まる
- **アビリティじゃんけん（6つの手）**

| 攻撃 | 守備 |
|---|---|
| 突破（LB） | タックル（LB） |
| シュート（RT または Y） | シュート妨害（RB長押し） |
| かわし（RB） | 間合い＝素の守備＋追走ステップ（B または LT） |

  - 突破 ＞ シュート妨害、シュート ＞ 間合い、かわし ＞ タックル
  - タックル ＞ 突破、シュート妨害 ＞ シュート、間合い ＞ かわし
  - 技の出始めは0.15秒前後（反応時間より短いので、見てからではなく読みで勝負）。外したときの隙は0.4〜0.6秒（確実に咎められる長さ）
  - 突破していない相手へのタックルは「当たっただけ」で、ボールは奪えない（タックルは突破に刺す技）
- **素の守備**：スティール（X）、ジャンプでのブロック（A。視線の先に手が出る）
- **予兆**：相手の腰の2本のリングが光っていれば技を使える（上＝LB系、下＝RB系）。技の出始めにはリングの色と音が変わる（タックル＝橙と低音、突破＝水色、かわし＝白、シュート妨害＝赤と赤いフィールド）
- **計測**：ポーズ画面に、攻撃1回あたりの得点、じゃんけんの結果の内訳、シュートの成功率の内訳が出る

## 操作
| 入力 | コントローラー | PC |
|---|---|---|
| 移動 / 視点 | 左スティック / 右スティック | WASD / マウス |
| シュート | RT（またはY）長押し → 緑で離す | 左クリック |
| ジャンプ（ブロック） | A | Space |
| 攻撃：突破 / かわし | LB / RB | Q / E |
| 守備：タックル / シュート妨害 | LB / RB長押し | Q / E（右クリック） |
| 守備：スティール / 追走ステップ | X / B（またはLT） | F / Shift |
| ポーズ | START | Esc |
| ポーズ中：プレイ / リスタート / コート倍率 / BOT強さ / カメラ | A / Y / BACK / X / LB | Enter / R / C / B / V |

コート倍率は1.0倍・1.15倍・1.3倍の3種類（RULES_V1.md §5.2の検証用）。BOTの強さは「練習・ふつう・強い・鬼」の4段階。

## Androidへのインストール
1. `TaG-prototype.apk` を端末にコピーして開く（「提供元不明のアプリ」のインストールを許可する）
2. コントローラーをBluetoothかUSBで接続する（Xbox / PlayStation / Switch Pro / 一般的なHIDコントローラー）
3. 横画面で起動する。コントローラーが見つからない場合は、画面下に案内が出る

- 対応：Android 7.0以上、arm64（2017年以降のほとんどの端末）
- 署名はプロトタイプ用の鍵でしている。今後、鍵を変えて作り直した版を入れるときは、先に古い版をアンインストールすること

## ビルド方法
```bash
# 1) 初回のみ：インポート
godot --headless --path prototype --import
# 2) APKの書き出し（Godot 4.7.2の書き出しテンプレートと、Android SDKのbuild-tools 35.0.1が必要）
export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=/path/to/release.keystore
export GODOT_ANDROID_KEYSTORE_RELEASE_USER=<alias>
export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=<password>
godot --headless --path prototype --export-release "Android" ../build/TaG-prototype.apk
```

## 検証用のモード
```bash
godot --headless --path prototype -- --autotest   # BOT同士で1試合して、計測値を表示する
godot --headless --path prototype -- --shottest   # 計画上「成功」のシュートが、物理で本当に入るかを距離ごとに確かめる
```

### 現時点の計測（v0.2、BOT強さ0.7対0.4、コート倍率1.15倍）
- スコア 11対9、シュートの成功率は約59%（v0.1は約40%）。読み勝ちは6回と4回
- 計画上「成功」のシュートは、全距離で物理でも入る（--shottest）
- 人が遊んだときの数値は、ポーズ画面の計測で確かめる

## ファイル構成
| ファイル | 中身 |
|---|---|
| `scripts/main.gd` | 試合の進行・コートの生成・入力の設定・じゃんけんの判定・計測・検証用のモード |
| `scripts/athlete.gd` | 選手（人間とBOT共通）。状態遷移・移動・6つの手 |
| `scripts/ai_brain.gd` | BOTの思考。手を混ぜる確率（混合戦略）と、相手の状態への反応 |
| `scripts/ball.gd` | ボール。保持・シュート・ルーズボール・得点の判定 |
| `scripts/hud.gd` | 画面表示・ポーズメニュー |
