# Basket Team-play TaG — 現実のバスケを超える v0.1

> **方針：これはバスケではなく、ナギサで生まれた競技「TaG（タグ）」だ。**
> バスケから受け継ぐのは3つだけ。残りは全部、面白さのために作り直す。

---

## 0. 残すもの／捨てるもの

| 残す（TaGらしさの核） | 捨てる・作り直す |
|---|---|
| ① ボールを運んで、リングに通すと点になる | 平らなコート → **壁と天井まで使える箱型のアリーナ** |
| ② パスとシュートの手応え | アウトオブバウンズ → **なし**（ボールは壁で跳ね返る） |
| ③ チームでボールを回すほど強くなる | リング1つ → **高さの違う3つのリング** |
| | 決まった点数 → **パスで充電した分だけ点が増える** |
| | ショットクロック → **ボールそのものが時限装置** |
| | 選手交代 → **試合中にその場でタッグ交代** |
| | 1つのコート → **試合が都市の層を落ちていく** |

> ギャザー制（ABILITY_DESIGN.md §4）は残す。ただし理由は「現実のルールだから」ではなく、ボールの独占を防ぐためのバランス調整だ。

## 1. 採用する6つの大胆な仕組み

### ① 臨界コア：ボールそのものがショットクロック
- ボールを手にした瞬間から **臨界タイマー** が動き出す（3on3は14秒、5on5は20秒）。
- **パスが1本通るたびに充電が+1（最大5）されるが、タイマーは1.5秒縮む。**
  - パスで点を増やすほど、残り時間が減る。「あと1本つなぐか、ここで打つか」というチキンレースになる。
  - 2人で短いパスを往復させて稼げないように、**6m以上飛んだパスだけを数える**。
- **得点 = リングの基本点 + 充電の数**（＋ディープラインより外からなら1点）
- タイマーが0になると **臨界放電** が起きる。持っている人はダウンし、ボールは充電0のルーズボールになる。
- **スティールやブロックで奪ったボールは、充電の半分（端数切り捨て）を引き継ぐ。** 守備から一気に大量点を取れるので、逆転の種になる。
- 世界観での理由：充電されたコアは臨界に近づく。ゴール炉に入れなければ暴発する。
- 先行例への対策：Speedball 2には得点倍率の仕組みがあり、倍率が自分に有利になるまで両チームがゴールを狙わず、試合が停滞する問題があった。本作はタイマーが常に動いているので、停滞は起きない。

### ② ケージ・アリーナ：壁も天井もコートの一部
- 床・壁・天井で囲まれた箱型のアリーナにする（角は曲面）。**アウトオブバウンズはない。** 壁を使ったバンクパスや、天井に当てるシュートも狙える。
- **全員が短い壁走り（1.2秒）と壁ジャンプをできる。** ただし体格で差を付ける：
  - S・M：壁走りができる（Sは長く走れる）
  - L・XL：壁走りはできない。代わりに **着地の衝撃** で周りの相手を減速させる
- 壁走りは地上を走るより速くする。Titanfall 2の開発でも、地上を走るのと同じ速さだと誰も壁を走らなかったという教訓がある。
- 3on3は小さいケージ（ストリートの金網コートのイメージ）、5on5は大きいアリーナにする。

### ③ 三層リング：高さが戦術になる
各チームのゴール側に、高さの違うリングを3つ置く。

| リング | 高さ | 基本点 | 決め方 | 主に守るロール |
|---|---|---|---|---|
| **ゲート** | 床の高さ（縦に立てた輪） | 1 | ボールを持ったまま **走り抜けると** 得点 | ウォール（正面に立てば塞げる） |
| **ゴール炉** | 3.05m | 2 | 通常のシュートかダンク | 全員 |
| **スカイ炉** | 天井近く（約9m） | 4 | 壁走り・ジャンプパッド・アビリティでしか届かない | 守りにくい。高さで勝負するチームの切り札 |

- 例：充電5のボールをスカイ炉に決めると9点になる。
- ウォールは低いゲートを塞ぎ、スコアラーは中段を、壁走りの得意なキャラは天空を狙う。**ロールと体格で狙うリングが分かれる。**

### ④ コア・ストライク：充電を撃ち出す
- **充電3以上のボールを相手の体に直接投げ当てると、「充電の数 × 20」のガードを削れる**（充電5なら100で、Mクラスはほぼダウンする）。
- 当てた後のボールは充電0のルーズボールになる。**点に使うか、相手を倒すために使うか** の選択になる。
- **キャッチで返せる**：狙われた側が、ちょうどいいタイミングでスティールのボタンを押すと、ボールを受け止められる。**受け止めたボールは充電がそのまま残る。** 一人称視点で一番盛り上がる瞬間になる。
- 先行例：Speedball 2にも、充電したボールを投げて相手選手をなぎ倒す仕組みがある。

### ⑤ 降下式コート（5on5）：試合が都市を落ちていく
- 5on5の1試合は、**3つのステージ** で構成する。

| ステージ | 層 | 特徴 |
|---|---|---|
| 1 | 上層「ソラノハ」 | ガラスの床。重力はやや低く、高く跳べる |
| 2 | 中層「テツバ」 | 鉄骨の標準的なアリーナ |
| 3 | 下層「ソコマチ」 | 浸水している。床の上は遅くなり、壁走りとスカイ炉の価値が上がる |

- 4分が経つか、両チームの合計点がしきい値に届くと **床が割れて、全員とボールが下の層へ落ちる**。点数はそのまま持ち越す。
- 落ちている間のボールを、空中で奪い合う（**降下ボール**。ジャンプボールの代わり）。**ステージが変わるたびに、施しではないチャンスが自然に生まれる。**
- ステージごとに有利なヒーローが変わるので、タッグ交代（⑥）と噛み合う。
- 世界観での理由：リーグ公式の **ダイブ・マッチ**。上層から始まり、最後は下層で決着する。「上層の企業も、最後は下層で戦う」。
- 3on3はステージ1つだけ（地区のストリートケージ）。

### ⑥ タッグ交代：TaGの名前を2つの意味で回収する
- 試合の前に **メインとサブの2体** を選ぶ。プレイヤーが操作するのは「タッグ（2人組）」になる。
- **いつでもその場でタッグ交代** できる（クールダウン25秒。ボールを持っている間はできない）。
  - 交代するときは0.8秒無防備になる。入ってくる側は **タッグイン突進**（短い突進と、小さなノックバック）で登場する。
  - ガードとウルトはヒーローごとに別々に持つ。ベンチにいる間はガードがゆっくり回復するので、ローテーションを考える意味が出る。
- ランクマッチでは **サブはメインと同じロール**（ロールの構成を守るため）。カジュアルでは自由にする。
- 体格のミスマッチを付かれたら交代で返す、ステージが変わったら交代する、というように **試合中に読み合いが続く**。
- 世界観での理由：選手は、TaGで同期した **2人1組のコンビ** で登録する。ベンチ側の相方はサイドラインにいて、一人称視点からも見える。
- 名前の回収：**TaG = Tandem-amplified Gear（装置）であり、Tag（タッグ交代）でもある。**

## 2. 実験枠（プロトタイプで試して、ダメなら捨てる）

| 案 | 中身 | 懸念 |
|---|---|---|
| 重力反転ゾーン | アリーナの一部では天井に立てる | 酔い。上下が分からなくなる |
| 動くリング | 3on3のマップのギミックとして、リングがレールの上を動く | 狙う楽しさが運に寄る |
| リング封印 | ウルトで相手のリングを5秒間閉じる | 強すぎる。得点を保証しない原則とのバランス |
| デコイボール | 本物と同じに見える分身のボールを投げる | 一人称で見分けがつかず、イライラする |
| 陣取りリング | ゲートを奪うと、そのチームの得点の倍率が上がる | Speedball 2と同じ停滞が起きるおそれ |

## 3. 一人称で見て分かるようにする
- **ボールの状態は色と音で伝える**：充電0〜5で発光が強くなり、臨界が近づくと唸り音が高くなる。タイマーの数字は画面に出すが、見なくても分かるようにする。
- **スカイ炉の位置は、常に画面の端にマーカーで出す。**
- **壁走り中は、カメラを壁から少し離れる方向へ傾ける**（Titanfall 2と同じ手法）。傾きの量は酔い対策の設定で弱められるようにする。
- **壁には格子の模様と照明を入れる**：Rocket Leagueのコミュニティでは、ボールと壁の距離が目で分かりにくいという指摘がある。
- **競技用のアリーナは寸法を標準化する**：Rocket Leagueも、オンラインのモードではアリーナの寸法をそろえ、プロ選手に好評だった。ギミックはカジュアルのマップと降下式のステージに回す。

## 4. 既存のドキュメントへの影響
- **CONCEPT.md §1（得点・ショットクロック）**：本書の臨界コアと三層リングで上書きする。3on3の勝利条件は「**30点先取または10分**」を仮の値とする（充電があるぶん1回の攻撃で入る点が増えるため）。
- **CONCEPT.md §4（オーバーコア）**：「最初から充電5の中立球」として再定義する。
- **ABILITY_DESIGN.md**：ショットクロックの直接操作の禁止は、**臨界タイマーにもそのまま適用** する。ボールに作用するアビリティの特別枠は、壁でのバンクと組み合わせて広げる。
- **ROSTER.md**：体格パラメータに「壁走り」を追加した。
- **TECH.md**：ボールの物理には、壁と天井での跳ね返り、3種類のリングとの当たり、ストライクとキャッチの判定を加える。
