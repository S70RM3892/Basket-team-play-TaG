# Basket Team-play TaG — 競技ルール v1：普通のバスケ ＋ アビリティじゃんけん

> **方針**：土台は普通のバスケ。そこにアビリティを足して、**1対1の攻防をじゃんけんの構造にする**。
> 臨界コアやコア・ストライク（ボールを爆弾のように扱う仕組み）は廃止した（BEYOND.mdは廃案として保存）。

---

## 1. 結論の要約

| 問い | 結論 |
|---|---|
| 理論値では、攻めと守りのどちらを強くするか | **攻めを少しだけ強くする。** 1回の攻撃あたりの得点の期待値は1.05〜1.15点が目安（NBAの平均とほぼ同じ） |
| どうやって調整するか | **じゃんけんの形（どれがどれに勝つか）は対称のまま保つ。** 勝ち・あいこ・負けのそれぞれで何点動くか、という結果の重みで攻守の強さを調整する |
| 協力をどう強くするか | **1対1の期待値は低く、連携した攻めの期待値は高く** なるように数値を決める（実在のNBAもそうなっている） |
| コート | **普通のコートを使う**（3on3はハーフコート、5on5はフルコート、バックボードあり）。中央のポールを囲むドーナツ型のリングは採用しない |
| 逆転の仕組み | **足さない。** バスケの得点の構造そのものに、負けている側が追いつく力がある（§2.3）。クラッチタイムとオーバーコアは凍結する |

---

## 2. 理論：なぜ「攻めが少し強い」が正解なのか

### 2.1 守りが強すぎると壊れる
- 1950年のNBAで、ピストンズがレイカーズに **19対18** で勝つという史上最少得点の試合があった。リードした側がほぼ試合中ずっとボールを持ち続けて時間を潰した結果だ。
- これをきっかけに、1954年に **24秒のショットクロック** が導入された。**攻めなくても損をしない構造にすると、勝っている側は攻めなくなる。**
- 得点が少ない競技ほど、1点の重みが大きくなり、運が勝敗を左右する。研究では、番狂わせ（弱い側が勝つ）の頻度は、サッカーが0.452、バスケが0.365だった。**得点の機会が多いバスケは、実力が結果に出やすい。**

### 2.2 攻めが強すぎても壊れる
- 攻撃がほぼ毎回決まるなら、交互に点を取り合うだけになる。**守備で止める（ストップ）が起きなければ、点差は縮まらない。**
- 逆転には、「止める → 点を取る」の流れが必要だ。だから守備が勝つ場面も、十分な頻度で起きなければならない。

### 2.3 バスケには、最初から逆転の力が入っている
- NBAの得点の推移は、ほぼランダムウォーク（ランダムに上下する動き）として説明できる。そこに次の2つが加わる。
  1. **点を取った側は、ボールを相手に渡す**（交互に攻撃する）ので、同じチームが続けて点を取る確率が下がる。続けて取る確率は約0.36
  2. **負けている側のほうが、わずかに高い頻度で点を取る**（弱い「引き戻す力」がある）
- つまり、得点の機会が多く、攻守が交互に入れ替わる構造そのものが「最後までチャンスがある」を作っている。**人工的な逆転の仕組みは要らない。**

### 2.4 目標の数値
| 指標 | 目標 | 現実の参考値 |
|---|---|---|
| 1回の攻撃あたりの得点の期待値（全体平均） | **1.05〜1.15** | NBAの2024-25シーズンの平均は、100回の攻撃あたり114.5点 |
| 1対1で強引に攻めたときの期待値 | **0.85〜0.95**（全体平均より低くする） | NBAのアイソレーション（1対1）は0.886。全体平均は1.088 |
| 連携した攻め（カット、フリーでのシュート）の期待値 | **1.10〜1.25** | NBAのカットは1.13前後 |
| 攻撃が1点も取れずに終わる割合 | **45〜50%** | 守備のストップが、試合の流れを変える出来事として成り立つ |

> **1対1で攻めるより、連携したほうが得をする。** 「協力が一番気持ちいい」という柱を、数値で保証する。

## 3. アビリティじゃんけん

### 3.1 1対1での3すくみ
ボールを持っている攻撃側と、マークしている守備側は、それぞれ3つの行動から選ぶ。

| 攻撃側 \ 守備側 | **タックル**（タックル系） | **シュート妨害**（妨害系） | **間合い**（素の守備＋移動系） |
|---|---|---|---|
| **突破**（移動系） | ✕ 止められる | ◯ 抜き去る | △ 抜けずに仕切り直し |
| **シュート**（素のシュート） | △ 当たられながら打つ | ✕ 妨害される | ◯ 空いた間合いから打つ |
| **かわし**（妨害回避系） | ◯ 空振りさせて抜く | △ 何も起きない | ✕ 見切られて無駄撃ち |

- **どの行動も、1つに勝ち、1つに負け、1つとあいこ。** 完全に対称なじゃんけんになっている。
- どれも実在のバスケの理屈と一致している：
  - シュート妨害のために詰めてきた相手（クローズアウト）は、突破で抜かれる
  - 間合いを空けた相手には、シュートを打たれる
  - 飛び込んでくるタックルは、かわしで空振りさせられる
  - 我慢して構えている相手には、フェイクが効かない
- **ユーザーが挙げた4つの系統はすべて入っている**：移動系（攻撃は突破、守備は間合いを保つための追走）、タックル系、シュート妨害系、妨害回避系（かわし）。
- **シュートと間合いはアビリティなしでも出せる**。アビリティを使わない素のバスケの技術も、じゃんけんの一部になる。

### 3.2 結果の重みで攻守を調整する
じゃんけんの形が対称なので、両者が最適に手を混ぜると、どの手も1/3ずつになる。その場合の期待値は、単純に **（勝ち＋あいこ＋負け）÷3** で決まる。

| 結果 | 中身 | 攻撃側の期待値（初期の仮の値） |
|---|---|---|
| 攻撃側の勝ち | ノーマークのシュート、または抜き去り | +1.40（2点シュートの成功率70%） |
| あいこ | 相手に寄られた状態でのシュート、または仕切り直し | +0.80（成功率40%） |
| 守備側の勝ち | ブロック、スティール、ダウン | −0.20（相手の速攻につながる分） |
| **1対1の期待値** | | **(1.40 + 0.80 − 0.20) ÷ 3 ≒ 0.67** |

- 1対1だけで攻めると、期待値は約0.67で、目標（0.85〜0.95）よりかなり低い。**シュートの成功率は、P1の段階でこの目標まで上げる。**
- 攻撃全体の期待値を1.1まで押し上げるのは、**連携** だ。パスで「2対1」を作る、守備がアビリティを使った直後（クールダウン中）の選手を狙う、スクリーンでマークを入れ替える、といった攻め方がそこを埋める。
- **調整のつまみは3つの数値だけ。** じゃんけんの形には手を付けないので、バランスが崩れにくい。

### 3.3 リアルタイムのじゃんけんにするための時間設計
- 人間が目で見てから反応するまでの時間は、およそ **0.2〜0.3秒**。耳で聞いたときのほうが、目で見たときより反応が速い。
- **発生（出始め）は0.15〜0.20秒にする**。反応が間に合わない長さなので、見てから対応するのではなく、**読み** で勝負することになる。
- **外したときの硬直（隙）は0.4〜0.6秒にする**。反応が間に合う長さなので、**外したら確実に咎められる**。
- 予兆は音でも出す（音のほうが速く反応できる）。読み勝った・読み負けたが、その場ではっきり分かるようにする。

### 3.4 クールダウンの読み合い
- 守備側がタックルを使った後のクールダウン中は、攻撃側の突破が負けなくなる。そのため、**相手のクールダウンを覚えて、穴を突く** ことが上手さになる。
- 守備側は、味方のヘルプでその穴を埋める（数的不利を連携でカバーする）。→ **じゃんけんの外側で、チームの連携が勝敗を決める。**
- 各アビリティのクールダウンは、相手から見えるようにする（TaGの発光が消えているかどうか）。

### 3.5 アビリティの分類
すべてのアビリティに、次のどれかのタグを付ける。

| タグ | 側 | 例 |
|---|---|---|
| 突破 | 攻撃 | ブリンク、ダッシュ |
| シュート | 攻撃 | 長距離シュート、クイックリリース（シュート妨害には負けるまま） |
| かわし | 攻撃 | スピン、残像ステップ |
| タックル | 守備 | ショルダーチャージ、遠距離からの引き寄せ |
| シュート妨害 | 守備 | 妨害フィールド、壁 |
| 間合い | 守備 | 追走のステップ、減速フィールド |
| **連携** | 両方 | パスの強化、テザー、遠くからの起こし、スクリーンの強化。1対1のじゃんけんには参加しないが、2対1を作る |

> **シュート妨害の範囲型アビリティ（妨害フィールド）は、一定時間出し続ける** ものにする。一瞬だけ跳ぶ型にすると、フェイク一発で釣れてしまい、かわしがシュート妨害にも勝ってじゃんけんが崩れる。素のブロック（照準でボールを叩く）は、これとは別にFPSの腕前として残す。

## 4. 初期6体のキットをじゃんけんに当てはめる

| ヒーロー | ロール | アビリティ1 | アビリティ2 | 得意なこと |
|---|---|---|---|---|
| ガンテツ | ウォール | ショルダーチャージ〔タックル〕 | 壁〔シュート妨害〕 | 守備の手が2種類ある。読み負けにくい |
| ミナモ | ウォール | 引き寄せ〔タックル・遠距離。発生が遅い〕 | 減速フィールド〔間合い〕 | ゴール下の番人 |
| レイ | スコアラー | ブリンク〔突破〕 | 残像ステップ〔かわし〕（v0.4のフェイダウェイから変更） | 攻めの手が2種類あり、1対1が強い |
| ハヤテ | スコアラー | スコープ〔シュート・長距離〕 | スポットアップ〔連携・ボールなしで使える〕 | 連携から打つシューター |
| ツムギ | プレイメーカー | 糸パス〔連携〕 | テザー〔連携〕 | 2対1を作る |
| ヒビキ | プレイメーカー | 音波〔シュート妨害・範囲〕 | 遠くからの起こし〔連携〕 | 守備のヘルプ役 |

- **ロールによって、じゃんけんの手札の偏りが変わる。** ウォールは守備の手が多く、スコアラーは攻撃の手が多い。プレイメーカーは、じゃんけんの外側（連携）で勝つ。
- 「1つの手しか持っていない」ヒーローは、読まれやすい代わりに、その手の性能を高くする（例：ミナモの引き寄せは射程が長い）。

## 5. コート：普通のコートにする

### 5.1 中央のポールを囲むドーナツ型のリングは採用しない
- **実在の前例がある**：コーフボールは、高さ3.5mのポールの上にバックボードなしのかごが付いていて、ポールの裏側からもシュートできる。
- それでも採用しない理由：
  1. **バックボードがなくなる**：レイアップ、バンクショット、ボードを使ったアリウープが消える（指摘のとおり）
  2. **360°から攻められるので、攻めが強くなりすぎる**：普通のコートでは、ベースラインとサイドラインが「もう1人の守備」として働き、攻める方向が絞られる。全方向から攻められると、移動系のアビリティで抜くコースが無限になり、§2.4の目標の数値を守れない。なお、コーフボールはドリブル自体が禁止で、攻めの手段がもともと弱い
  3. **一人称だとポールが視界を遮る**。自分がポールのどちら側にいるのかも把握しにくい
  4. **戦術の地形が消える**：ボールがある側とない側、コーナー、ペイントエリア、トラップに追い込む場所といった、戦術の基準がなくなる
- 遊びのモード（パーティー用のマップ）としてなら、後で試す価値はある。

### 5.2 普通のコートの寸法について
- 3on3はFIBA 3x3と同じハーフコート、5on5はフルコートにする。バックボードとリングの高さ3.05mは実寸のまま。
- 移動系のアビリティがあるぶん、実寸ではコートが狭く感じる可能性がある。**P1では、実寸の1.0倍・1.15倍・1.3倍の3種類を作って試す。**

## 6. 廃止・凍結するもの
| 区分 | 項目 |
|---|---|
| **廃止** | 臨界コア、コア・ストライクとキャッチ、三層リング、ケージ・アリーナ（壁や天井を使う）、ディープライン |
| **凍結** | クラッチタイム、オーバーコア、降下式コート、タッグ交代（中身は良いので、人が集まった後の拡張候補として残す） |
| **そのまま使う** | 一人称、照準によるブロックとスティール、ギャザー制、体格システム、ダウンと仲間による即復帰、ロール、世界観（TaG、ナギサ） |
| **得点** | 普通のバスケと同じ。3on3は1点／2点（FIBA 3x3）、5on5は2点／3点 |

## 7. 次の検証（P1）
1. 素のバスケ（ドリブル、パス、シュート、照準でのブロックとスティール）を1on1で作る
2. じゃんけんの6つの手（タグごとに1つずつ）を、汎用のアビリティとして入れる
3. 計測する：**1対1の期待値、手ごとの選ばれ方の偏り、読み勝った時の手応え**
4. 2on2にして、**連携した攻めの期待値が、1対1の期待値を上回るか** を確かめる
