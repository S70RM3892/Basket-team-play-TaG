# Basket Team-play TaG — アビリティ設計の原則 v0.1

> **v1の注記**：アビリティの一番上の分類は、[RULES_V1.md](RULES_V1.md) §3 のじゃんけん（突破・シュート・かわし／タックル・シュート妨害・間合い／連携）とする。本書の「ズレ」「ギャザー制」「バスケの動作で対抗できる」は、引き続き有効。

> **結論：アビリティは、バスケで勝つための「ズレ」を作る道具にする。バスケの動作を置き換えるのではなく、誇張する。**
> アビリティを使っても点は自動では入らない。最後に点を取るのは、パスとシュートだ。

---

## 1. 4つの原則

| # | 原則 | 意味 | 破るとどうなるか |
|---|---|---|---|
| ① | **バスケの動作を拡張する** | どのアビリティも、ドリブル・パス・シュート・スクリーンなど、バスケの動作のどれかを強化する | ボールそっちのけの格闘ゲームになる |
| ② | **ズレを作る。得点は保証しない** | アビリティが作るのは「有利な状況」までにする | 点が自動で入り、バスケの上手さが意味を失う |
| ③ | **バスケの動作でカウンターできる** | どのアビリティにも、スキルを使わずにバスケの動作で対抗する手段がある | クールダウンを持っている側が必ず勝つ |
| ④ | **ボールの近くほど効く** | ガードを削る効果は、ボールの近くで最大になる | ボールから遠い場所での殴り合いが生まれる |

### ④の世界観での理由
充電されたコアボールの周りには **コア場** という場ができ、TaGの出力が上がる（WORLD.md §3）。
- ボールから **半径8m以内**：ガードを削る効果は100%
- それより外：50%
- 移動・空間・視界に関わるアビリティには、この補正をかけない（ボールのないところでのスクリーンやカットは、バスケとして正しい動きなので邪魔しない）

---

## 2. ズレの4種類（アビリティの「仕事」を分類する）

バスケのオフェンスは、ディフェンスとの間に **ズレ（アドバンテージ）** を作って、それを広げて得点する競技だ。アビリティは、必ずどれかのズレを作る。

| ズレ | 内容 | アビリティの例 |
|---|---|---|
| **位置のズレ** | マークを外してフリーの選手を作る | ブリンクでのドライブ、壁によるスクリーン、足音の偽装 |
| **数のズレ** | 一時的に4on5や2on1を作る | ガードを削ってダウンさせる、相手を減速させる、相手を引き寄せる |
| **高さのズレ** | 体格のミスマッチを作る（ROSTER.mdの体格システムと直結） | マークを強制的に入れ替えて、相手のウォールを小さいスコアラーに付けさせる |
| **時間のズレ** | 相手より先に動ける時間を作る | シュートの溜めを短くする、加速、スキルのクールダウンのリセット |

> キャラごとに得意なズレを決めると、ロールの中でも個性が出る。例：レイは位置、ミナモは高さ、ヒビキは時間。

---

## 3. バスケの戦術を、アビリティで「誇張」する

実在の戦術をそのまま強化した形にすると、バスケを知っている人は直感的に分かるし、知らない人はゲームを通してバスケの戦術を覚えられる。

| 実在の戦術 | 中身 | アビリティで誇張した形 | ヒーロー |
|---|---|---|---|
| **ピック＆ロール** | スクリーンでマークを外し、スクリーンをかけた側はゴールへ走る（ロール） | 壁の横を通った味方が加速する。壁を消した瞬間にガンテツ自身もゴール下へ突っ込む | ガンテツ |
| **ギブ＆ゴー** | パスを出してすぐに走り込み、リターンパスを受ける | パスを出した相手と糸でつながり、リターンパスが必ず通る線を作る | ツムギ |
| **バックドアカット** | マークの背後を突いてゴールへ走る | 相手の背後へ短距離ブリンクする（ボールを持っていなくても使える） | レイ |
| **アリウープ** | 空中でパスを受けて、そのまま決める | 2人のスキルを重ねてシンクロ技として出す | ツムギ×レイ |
| **キャッチ＆シュート** | 止まって待ち、パスを受けたらすぐに打つ | 止まっている間は、パスを受けてからのシュートの溜めが半分になる | ハヤテ |
| **ボックスアウト** | リバウンドで体を張り、相手を外に締め出す | 自分の周りに減速フィールドを張る | ミナモ |
| **スイッチ** | ディフェンスがマークの相手を入れ替える | 相手1人を引き寄せて、マークを強制的に入れ替える | ミナモ |
| **ゾーンディフェンス** | 人ではなく、場所を守る | 根を張った範囲に入った相手を遅くする | コケマル |
| **ヘルプとローテーション** | 抜かれた味方を、別の味方がカバーする | ダウンした味方を遠くから起こす。照らした相手の輪郭を味方に見せる | ヒビキ、トモシビ |
| **速攻** | 守備から一気に攻めに転じる | 味方と糸でつながって2人とも加速する。スティール直後に加速する | ツムギ、スズ |

## 4. ボールを持っている間のルール：ギャザー制

**現実のバスケのルールを、アビリティの制限として使う。**

- NBAのルールには「ギャザー」という定義がある。ボールを両手で保持した瞬間から、パスかシュートか停止までに **2歩** まで許される（2019年にルールブックで明文化された）。
- 本作では：**ボールを持ったまま移動系のアビリティ（ブリンクなど）を使うと、その時点でギャザー扱いになり、ドリブルが終わる。**
  - そこからは **2歩（約0.6秒）以内に、パスかシュートをする**。それ以外にできるのはピボット（軸足を残した回転）だけ
  - つまり、ブリンクで抜いたら、そのまま打つかパスするかの決断を迫られる（実在のユーロステップに近い）
  - アビリティでボールを持ち続けて独占する「ボール独占」の戦い方を、ルールで封じる
- ドリブルをしながら使えるのは、**「ドリブル」タグの付いたアビリティだけ**（クロスオーバーの強化など）

---

## 5. ボールを持っていない時間に価値を持たせる

- 3on3では、自分がボールを持っている時間は約1/3。5on5では約1/5しかない。
- 一般的なヒーローシューターのアビリティは、自分が戦うためのものになりやすい。本作でそれをやると、**ボールを持っていない間の時間が退屈になる。**
- **ルール：どのヒーローも、ボールを持っていなくても役に立つアビリティを最低1つ持つ。** スクリーン、カット、ヘルプ、パスの受け方の強化など。
- **ウルトは「セットプレーの合図」にする**：ウルトが溜まると自動でピンが出る。発動の0.5秒前に掛け声を出して、味方が合わせて動けるようにする。

---

## 6. ボールそのものに作用するアビリティ（特別枠）

ボールの軌道を曲げる、ボールを運ぶなど、ボールに直接作用するアビリティはバスケらしさが一番強い。そのぶん強すぎて、見て分かりにくくなりやすい。

- 1ロールにつき2体くらいまでに限る（例：カザミの風、ツバメ便のドローン）
- **ボールの当たり判定の大きさは変えない**
- 軌道が変わるときは、**必ず予告線と音を出す**
- ボールの持ち主を、スティール以外の方法で奪わない（盗むのはエイムで）

---

## 7. 一人称視点で見て分かるようにする

- **予兆の3点セット**：発動の前に、音・光・TaGの発光（チームの色）を必ず出す
- **背後で発動したアビリティは、音で方向が分かる** ようにする（立体音響）
- 視界を完全に奪うアビリティは作らない（一人称ではボールが見えなくなり、不快なだけになる）
- 動けなくする効果（スタン）は **最長1.0秒** までにする。バスケのテンポを止めないため

---

## 8. やってはいけないこと

| やってはいけないこと | 理由 | 代わりにどうするか |
|---|---|---|
| 得点を保証する | ②に反する | 成功率を上げる、またはブロック不可にする代わりに溜めを長くする |
| ボールに関係なくガードを削り続ける | ④に反する | コア場での補正 |
| 長いスタン、透明化 | 一人称で見ていて不快。テンポも止まる | 減速、相手の視点のずれ（フェイク） |
| ショットクロックを直接操作する | 強すぎて、何が起きたか分かりにくい | 時間のズレ（溜めの短縮、加速）で間接的に作る |
| 持ったまま使える移動スキルを連発する | ボールの独占になる | ギャザー制 |

## 9. 初期6体を原則に当てはめて見直す

| ヒーロー | アビリティ | 拡張するバスケの動作 | 作るズレ | ボールなしで使えるか | バスケの動作での対抗手段 |
|---|---|---|---|---|---|
| ガンテツ | 壁 | スクリーン | 位置 | ○ | ロブパスで越える。壁の端から回り込む |
| | ショルダーチャージ | ポストアップ、ボックスアウト | 数 | ○ | 横へのステップでかわす |
| ミナモ | 引き寄せ → **マークの強制入れ替え（変更）** | スイッチ | **高さ** | ○ | 入れ替えられた後に、すぐパスを回す |
| | 減速フィールド | ボックスアウト | 数 | ○ | フィールドの外からロブを打つ |
| レイ | ブリンク | ドライブ、バックドアカット | 位置 | ○（カット） | 着地点を読んで待つ。持ったまま使うとギャザーになる |
| | フェイダウェイ | シュート | 位置 | × | 打つ前にディフェンスで詰める |
| ハヤテ | スコープ | シュート | 時間 | × | スコープ中は視野が狭いので、横から寄る |
| | バックステップ → **スポットアップ（変更）** | キャッチ＆シュート | 時間 | ○ | パスの通り道を切る |
| ツムギ | 糸パス | パス | 位置 | — | 糸の通り道に立ってスティールする |
| | 糸のテザー | ギブ＆ゴー、速攻 | 時間 | ○ | 2人の間に立って糸を遮る |
| ヒビキ | 音波 | ヘルプディフェンス | 数 | ○ | 音波の前兆（重低音）を聞いて避ける |
| | 遠隔での起こし | ローテーション | 数 | ○ | 起こす前に攻め切る |

**見直した点**：
- ハヤテのアビリティは、どちらもボールを持っている間しか使えなかった。バックステップをスポットアップに替え、ボールなしでも役に立つようにした。
- ミナモの引き寄せはマークの強制入れ替えにした。これで体格のミスマッチ（高さのズレ）を作る役になる。

## 10. 新しいアビリティのチェックリスト

```
[ ] 拡張するバスケの動作は？（ドリブル／パス／シュート／スクリーン／カット／リバウンド／ブロック／スティール／ヘルプ）
[ ] 作るズレは？（位置／数／高さ／時間）
[ ] ボールを持っていなくても価値があるか？（キットに最低1つは必要）
[ ] スキルを使わずに、バスケの動作で対抗できるか？
[ ] 一人称で、予兆が見えるか・聞こえるか？（背後でも分かるか）
[ ] 得点を保証していないか？
[ ] ボールを持ったまま使う場合、ギャザー制に従うか？
[ ] 3on3と5on5で、強さが極端に変わらないか？（モード別の係数で調整できるか）
```
