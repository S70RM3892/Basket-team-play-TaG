## 2. 舞台：積層都市ナギサ

- 海面上昇から約60年後の湾岸メガシティ。古い街の上に新しい街を重ねたため、**上層・中層・下層** の三層構造になっている。
- 都市の電力は慢性的に足りていない。各地区への電力の配分（**給電権**）は、毎シーズンのリーグ戦の成績で決まる。
- 上層には企業がある。下層は半分水に沈んでいる。上の地区ほど明るく、下の地区ほど暗い。

## 3. 核となる技術：TaG（タグ）

**TaG = Tandem-amplified Gear（タンデム増幅ギア）**。手首と足首に付ける装置。

- 体の動きを電気（運動エネルギーからの発電）に変える。**1人ではほとんど発電しない。**
- 仲間の心拍と動きに **同期（タンデム）** したときだけ、出力が跳ね上がる。そのとき出る特殊な力を **アーツ** と呼ぶ。これがゲーム中のスキルとウルトにあたる。
- 元々はビルの解体現場で、作業員どうしの連携作業のために作られた工業用の装置だった。

### ゲームの仕組みと世界観の対応

| ゲームの仕組み | 世界の中での理由 |
|---|---|
| スキル・ウルト | TaGが同期したときに出るアーツ |
| **チェイン**（パスをつなぐと強くなる） | ボールの正体は **コアボール** という蓄電球で、同期した仲間の手を渡るたびに充電される。チェインが乗るほどボールが強く光る |
| アシスト優遇 | 他人の手を経由したほうが同期が深まり、発電効率が上がる |
| 得点 | リングの正体は **ゴール炉**。コアボールの電力を地区の送電網に流し込む |
| **キルがない** | TaGにはリミッターがあり、人を殺すほどの出力は物理的に出せない（リーグ創設時の約束で、絶対に外せない） |
| **ガードゲージ** | TaGが張る衝撃吸収フィールド |
| **ダウン** | 衝撃を吸収しきれず、TaGが過負荷で一時停止した状態 |
| **触れて即復帰** | 仲間が触れることでTaGが **再同期（リシンク）** して再起動する。仲間がいなければ立ち上がれない |
| **ディープライン** | コートの外周にある **外縁リング**。遠いほど送電が難しく、決まると発電量が大きい |
| **クラッチタイム／オーバーコア** | 試合の最後の1分、都市の送電網に溜まった余剰電力が、中立の球 **オーバーコア** としてコートに放出される。「最後の1分は誰のものでもない」 |

> ゲームのルールでは、v0.2の「ゴールデンボール」を **オーバーコア** に改名する。

## 4. 歴史

1. **廃材の時代**：ソコマチの子どもたちが、捨てられた工業用TaGを付けてストリートバスケをした。パスを回すとボールが光り、街灯が点いた。
2. **発見**：測ってみると、チームで動いたときの発電効率が、旧式の発電所より高いことが分かった。各地区が非公式の試合で電力を奪い合い始める。
3. **リーグ化**：争いを収めるために、市が **ナギサ・タンデムリーグ（NTL）** を作った。「リミッターを外さない」「成績で給電権を決める」の2つが原則になった。
4. **現在**：上層の企業がTaGの最新型と専属チームを持つようになった。下層は旧式のTaGと路上で鍛えた連携で立ち向かう。**「企業か、ストリートか」** がリーグの対立軸になっている。

### シーズンごとの物語の種（ゲーム内イベントやキャラのセリフで少しずつ明かす）
- 給電権の計算式が上層に有利に操作されているという噂
- 地図にない地区ウラカゼの正体と、そこから来た無所属の選手レイ
- 初代リーグで何が起きて、リミッターが「絶対」になったのか

## 7. アートディレクション

- **キーワード**：潮風とネオン。和モダン × ストリート × 重工業
- **描画**：少し誇張したスタイライズ表現で、セル調寄りにする。リアル志向にはしない。動作を重くしないことと、一瞬で見分けられることを優先する
- **シルエットでロールが分かるようにする**（黒く塗りつぶしたシルエットだけで判別できるか試す）
  - ウォール：横に広く、重心が低い
  - スコアラー：縦に長く、身軽
  - プレイメーカー：糸・ケーブル・布など、長くたなびくパーツを持つ
- **チームの色は衣装と切り離す**：味方は青緑、相手は赤橙。TaGの発光と輪郭線の色だけで敵味方が分かるようにする。FPSでは見分けやすさが最優先
- **画面の情報を世界の中に置く**：チェインの段階はボールの発光の強さで、ウルトの溜まり具合は手首のTaGの光で伝える。画面上の表示を減らす
- **音**：地区ごとに音楽のジャンルを変える（テツバはインダストリアル、ソコマチは祭囃子とローファイ、ナリバはドラムンベース）。コアボールの唸り音はチェインに合わせて高くなる
